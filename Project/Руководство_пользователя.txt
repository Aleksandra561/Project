## Руководство пользователя для программы управления фермерскими рынками
0. Развернуть базу данных из дампа:
Предварительные условия:
 - У вас должен быть доступ к серверу PostgreSQL.
 - У вас должна быть роль (пользователь) с достаточными правами для создания и записи в базу данных.
 - Вы должны знать параметры подключения к серверу PostgreSQL (хост, порт, пользователь, база данных).

 - в командной строке выполните команду: createdb -h <host> -p <port> -U <user> <database>
где * 	<host>:  На имя хоста сервера PostgreSQL (например, localhost).
    *   <port>:  На номер порта сервера PostgreSQL (обычно 5432).
    *   <user>:  На имя пользователя с правами создания баз данных (например, postgres).
    *   <database_name>: На имя базы данных, которую вы хотите создать (например, Farmers).

 - для восстановления базы выполните команду psql -h <host> -p <port> -U <user> -d <database_name> -f <dump_file>
где *   <database_name>: На имя базы данных, в которую вы хотите восстановить дамп (например, Farmers).
    *   <dump_file>: На полный путь к файлу дампа 

1. Запуск программы:

1. Убедитесь, что на вашем компьютере установлен Python (команда python --version)
2.  Создание виртуального окружения с помощью модуля venv (рекомендуется):
    1.	Создайте в удобном для вас месте каталог для хранения данных окружения
    2.	Запустите командную строку и перейдите в созданный каталог (команда cd)
    3.	Проверьте содержимое каталога (команда dir)
    4.	Введите команду "python −m venv" и название каталога, в котором предполагается создание виртуального окружения:
    5.	Откройте проводник и проверьте, что в каталоге  создался указанный каталог venv.
    6.	Требуется активировать окружение. Для активации окружение запустите скрипт activate.bat внутри директории с виртуальным окружением
    venv\Scripts\activate.bat
    7. Проверьте, что успешно прошел процесс активирования и при запуске виртуального окружения появилось ее имя перед директорией

3. Убедитесь, что есть необходимая библиотека (psycopg2) в списке пакетов (команда -m pip list). 
4. Если библиотека отсутствует в списке, то для настройки правильной работы программы приложен файл requirements.txt, 
который содержит список пакетов Python и их версии. Для установки сохраните файл в свою директорию и выполните команду (pip install -r requirements.txt)
5. Сохраните код программы в файл с расширением .py
6. Запустите программу с помощью любого текстового редактора (vc code, Spider).

2. Подключение к базе данных:

1. После запуска программа запросит у вас параметры подключения к базе данных PostgreSQL:
  •  Введите имя базы данных: Введите имя базы данных, к которой нужно подключиться.
  •  Введите имя хоста: Введите имя хоста сервера PostgreSQL (например, localhost, если база данных находится на вашем компьютере).
  •  Авторизуйтесь: Введите имя пользователя для подключения к базе данных.
  •  Введите пароль: Введите пароль для указанного пользователя.
  •  Введите порт: Введите номер порта, на котором работает сервер PostgreSQL (обычно это 5432).
2. Укажите правильные параметры подключения, чтобы программа могла успешно подключиться к базе данных.

3. Главное меню:

После успешного подключения к базе данных программа отобразит главное меню с доступными опциями:
```
Сделайте ваш выбор: 
выбери интересующий пункт меню: 
 - Вывести все рынки - 1
 - Поиск рынка по названию города - 2
 - Поиск рынка по названию штата - 3
 - Поиск рынка по индексу - 4
 - Просмотр и добавление рейтинга и рецензии - 5
 - Удаление отзыва - 6
 - Выход - 0)

```
Выберите интересующий вас пункт, введя соответствующую цифру и нажав клавишу Enter.

Описание пунктов меню:

•  0 - Выход: Завершает работу программы.
•  1 - Вывести все рынки: Отображает список всех рынков в базе данных с разбивкой по страницам.
•  2 - Поиск рынка по названию города: Позволяет найти рынки, расположенные в указанном городе.
•  3 - Поиск рынка по названию штата: Позволяет найти рынки, расположенные в указанном штате.
•  4 - Поиск рынка по индексу: Позволяет найти рынки, расположенные по указанному почтовому индексу.
•  5 - Просмотр и добавление рейтинга и рецензии: Позволяет просмотреть существующие отзывы и рейтинги для выбранного рынка, а также добавить свой отзыв и оценку.
•  6 - Удаление отзыва: Позволяет удалить отзывы и рейтинги для выбранного рынка

4. Вывод всех рынков (пункт 1):

1. После выбора пункта "1" программа начнет выводить список рынков по страницам. На каждой странице будет отображаться определенное количество рынков (например, 10).
2. Для навигации по страницам используйте следующие команды:
  •  n: Перейти на следующую страницу.
  •  p: Перейти на предыдущую страницу.
  •  q: Выйти из режима просмотра рынков.

5. Поиск рынка по названию города (пункт 2):

1. После выбора пункта "2" программа запросит у вас название города.
2. Введите название города и нажмите клавишу Enter.
3. Программа выполнит поиск рынков в указанном городе и отобразит результаты.

6. Поиск рынка по названию штата (пункт 3):

1. После выбора пункта "3" программа запросит у вас название штата.
2. Введите название штата и нажмите клавишу Enter.
3. Программа выполнит поиск рынков в указанном штате и отобразит результаты.

7. Поиск рынка по индексу (пункт 4):

1. После выбора пункта "4" программа запросит у вас почтовый индекс.
2. Введите почтовый индекс и нажмите клавишу Enter.
3. Программа выполнит поиск рынков по указанному индексу и отобразит результаты.

8. Просмотр и добавление рейтинга и рецензии (пункт 5):

1. После выбора пункта "5" программа запросит у вас уникальный номер рынка.
2. Введите номер рынка и нажмите клавишу Enter.
3. Программа выполнит поиск отзывов и рейтингов для указанного рынка.
  •  Если для рынка найдены отзывы и рейтинги:
    *  Отобразится список существующих отзывов и рейтингов.
    *  Программа спросит, хотите ли вы добавить свой отзыв.
      *  Если вы ответите "y" (да), вам будет предложено ввести свой отзыв, оценку и авторизоваться (ввести свое имя). После этого ваш отзыв и рейтинг будут добавлены в базу данных.
      *  Если вы ответите "n" (нет), вам будет предложено ввести оценку для рынка.
  •  Если для рынка не найдены отзывы и рейтинги:
    *  Программа спросит, хотите ли вы добавить отзыв.
      *  Если вы ответите "y" (да), вам будет предложено ввести свой отзыв и авторизоваться (ввести свое имя). После этого ваш отзыв будет добавлен в базу данных.
      *  Если вы ответите "n" (нет), программа вернется в главное меню.
9. После просмотра отзывов (если они были найдены) программа спросит: "Вы будете удалять Ваш отзыв? y/n:".
1. Для удаления отзыва:
  •  Введите "y" (латинскую букву "y", означающую "да") и нажмите Enter.
2.  После ввода Y, нужно авторизоваться. Если пользователь - создатель отзыва, то отзыв будет удален.
3. После ввода данных, программа напишет: "Отзыв успешно удален".
4. Для отмены удаления отзыва:
  •  Введите "n" (латинскую букву "n", означающую "нет") и нажмите Enter.
5. Если вы откажетесь от удаления, программа напишет: "Отзыв удален не будет" и вернется в меню.

6. Некорректный ввод пункта меню:

•  Если в главном меню введен пункт, которого нет в списке, программа напишет: "Неверный пункт меню. Пожалуйста, выберите из списка." и вернется в главное меню.

10. Закрытие соединения с базой данных:

•  При завершении работы программы (неважно, каким способом - через пункт меню "0" или при возникновении ошибки) программа попытается закрыть соединение с базой данных.
•  Будет выведено сообщение "Соединение с базой данных закрыто.".

11. Выход из программы (пункт 0):

1. Выберите пункт "0" в главном меню.
2. Программа отобразит сообщение "Спасибо, что зашли!" и завершит свою работу.

Примечания:

•  Убедитесь, что у вас есть права на чтение и запись в базу данных, чтобы программа могла успешно выполнять запросы и добавлять новые записи.
•  Если у вас возникли проблемы с подключением к базе данных, проверьте правильность введенных параметров подключения.
